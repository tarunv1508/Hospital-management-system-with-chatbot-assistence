# ⚡ QUICK SETUP - Email & SMS Notifications

## STEP 1: Gmail Configuration (Required for Email) ⚙️

### 1.1 Generate App Password
1. Go to: https://myaccount.google.com/apppasswords
2. Select **Mail** → **Windows Computer**  
3. Click **Generate** and copy the 16-character password

### 1.2 Update backend.py
Open `backend.py` (Line ~25) and change:
```python
EMAIL_ADDRESS = "your-gmail@gmail.com"  # Your hospital Gmail
EMAIL_PASSWORD = "xxxx xxxx xxxx xxxx"  # 16-char app password from step 1.1
```

✅ Email is ready!

---

## STEP 2: SMS Configuration (Optional - For Actual SMS) 📱

### Option A: Enable SMS with Fast2SMS API ⭐ (Recommended)

1. **Create Fast2SMS Account:**
   - Go to: https://www.fast2sms.com/
   - Sign up and verify
   - Get API Key from Dashboard → API

2. **Update backend.py** (Line ~30):
   ```python
   SMS_API_KEY = "your-api-key-from-fast2sms"  # Replace with your key
   SMS_PROVIDER = "fast2sms"
   ```

3. **Done!** SMS will now send automatically ✅

### Option B: SMS Logging Only (No API Key Needed)

- SMS messages will be logged in console
- You can add actual SMS later by just adding the API key
- Keep default settings in backend.py

---

## STEP 3: Test It! 🧪

1. Start server: `python backend.py`
2. Go to: http://localhost:5000/appointment.html
3. Fill form and submit
4. Check your email for confirmation
5. Check phone for SMS (if API key added)

### Expected in Console:
```
✓ EMAIL SENT: Confirmation email successfully sent to user@gmail.com
✓ SMS SENT: SMS successfully sent to +919876543210
```

## 🆘 Common Issues

| Issue | Solution |
|-------|----------|
| Email not sending | Verify app password (not Gmail password) at https://myaccount.google.com/apppasswords |
| SMS not sending | Add Fast2SMS API key to backend.py |
| SMS only logging | No API key configured (this is normal, add key to enable actual SMS) |
| Invalid phone | Ensure format: 9876543210 or +919876543210 |
